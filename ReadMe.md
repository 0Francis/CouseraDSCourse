# Extracting & Visualizing Stock Data

IBM / Coursera "Python Project for Data Science". Downloads **Tesla** and
**GameStop** share prices with `yfinance` and annual revenue from MacroTrends,
then plots both side by side.

## Files

| File              | Purpose                                    |
|-------------------|--------------------------------------------|
| `data_fetcher.py` | Fetches stock prices and revenue tables    |
| `plotting.py`     | Draws the share-price vs. revenue charts   |
| `main.py`         | Runs the whole pipeline for both stocks    |

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
